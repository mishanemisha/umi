# umi: локальная практика

Нижняя вкладка «Практика» открывает меню «Формы глаголов» / «Уроки Genki». Задания соответствуют части тем Genki 3rd Edition, уроки 1–23. Существующие карточки, квизы и SRS сохранены. Дизайн согласован с реальными компонентами приложения: [аудит и соответствия](DESIGN-practice.md).

## Запуск

```sh
python3 -m http.server 5174 --bind 127.0.0.1
```

Открыть http://127.0.0.1:5174/#practice .

## Тренировки

- По умолчанию 20 заданий; выбор 10, 20, 40 или всех доступных в выбранном режиме.
- 23 темы, от 65 до 95 заданий в каждой; общий банк 2 343 задания (включая 506 вопросов смешанного чтения), 131 правило и 91 уникальное слово.
- Уровни «Базовый», «Тренировка», «Сложнее». В сложном уровне: выбор слов/форм из расширенного набора вариантов, близкие варианты чтения, два независимых пропуска, сборка с лишним блоком и вопросы по тексту.
- 1 496 заданий выбора, 440 заданий с пропусками, 407 сборок. Все 577 прежних заданий ввода преобразованы в выбор из 4–8 вариантов; эквивалентные формы принимаются. Банк включает разные форматы одних примеров: это не 2 343 полностью независимых учебных ситуаций. `familyId` объединяет такие варианты для разнесения при подборе.
- Сначала предлагаются ещё не встречавшиеся задания; варианты одного примера и задания одного навыка по возможности разнесены. После исчерпания новых вопросов повторяются давно встречавшиеся. В рамках одной тренировки ID не дублируются.
- «Комбинировать уроки» позволяет выбрать две или более темы. В режиме «Вместе» появляются вопросы по двум отдельным текстам A/B из выбранных уроков, вместе с обычными заданиями. Смешанные тексты используют только выбранные темы. Сохранения каждой комбинации независимы. При короткой тренировке и большом числе выбранных уроков набор тем распределяется случайно.
- В заданиях с двумя пропусками первая попытка оценивается для каждого пропуска отдельно. После проверки можно сразу перейти дальше даже при ошибке. Правильный пропуск засчитывается, а в очередь ошибок попадает только неусвоенный навык. Итог и общий счётчик учитывают отдельные ответы.
- Незавершённые тренировки разных тем сохраняются независимо. Открытие темы показывает кнопку продолжения; её запуск не заменяет сохранённый блок. Новые настройки применяются к следующему блоку. Завершённую тему можно тренировать снова; история и итог каждого прохода сохраняются.
- Когда выбранный фильтр содержит меньше заданий, чем запрошено, кнопка показывает реальное доступное число. Режим «Все» проходит весь выбранный набор.

## Контент

Собственные русские объяснения и японские примеры; упражнения учебника, аудио и иллюстрации не переносились. Контент — локальный пилот, `status: draft`; независимая языковая редактура ещё не выполнена. Есть темы всех 23 уроков Genki I/II, но грамматика, лексика, чтение и письменность покрыты частично. Это не полный учебник и не полный словарь. Маленькая подпись «≈ Genki I/II · урок N» показана в каталоге, теме и каждом задании; у смешанного текста указаны оба урока. Например, отдельные пункты официальной программы — ね/よ (урок 2), количественное も (урок 14), でしょうか (урок 12) — пока не имеют отдельного правила и серии практики. Некоторые темы сгруппированы или введены раньше программы (например, から).

По прямому запросу пользователя весь банк доступен в памяти при запуске, без API и загрузки по темам. Повторяющиеся объяснения объединяются при сборке и разворачиваются один раз в браузере. `content/practice-data.js` занимает около 3.35 MB UTF-8; оценка gzip — около 201 KB. Наличие этой оценки не означает, что Python HTTP-сервер включает сжатие.

Исходники: `tools/content/build_practice.py`, `practice_variants.py` и `expand_practice.py`. Генератор не вызывает модели и не скачивает контент.

```sh
python3 tools/content/build_practice.py
```

Источник связи тем с уроками: [официальная программа Genki 3rd Edition](https://bookclub2.japantimes.co.jp/download/files/genki3/genki-3rd_syllabus_E.pdf). Связь не означает партнёрство с издателем.

## Прогресс

Ключ `umi.practice.v1` в localStorage хранит первую попытку, подсказки, исправления, ошибки, навыки, ответы, перемешивание, сохранённые темы и завершённые тренировки. Старые сохранения из пяти заданий мигрируют без сброса. Старые ответы с вводом мигрируют к вариантам по нормализованному совпадению; неизвестный введённый текст можно ответить заново, первая попытка остаётся в истории. Старые частично верные ответы в двух пропусках пересчитываются из сохранённой первой попытки, без сброса прогресса.

Экспорт/импорт JSON включает все сохранённые темы; импорт проверяется до замены. Ошибки сначала повторяются на других примерах того же навыка; исходный вопрос доступен через 10 минут. До самостоятельного верного ответа ошибка остаётся в очереди.

Слова добавляются по постоянному word_id. Совпадения с существующими карточками сохраняют их ID, папку, значение и SRS. История практики не переписывает повторения карточек. Пользовательские результаты не хранятся в исходниках.

## Проверки

```sh
node --test tools/content/practice.test.cjs
node --check content/practice.js
node --check content/practice-data.js
```

36 тестов: ссылки и ответы банка, все экраны, размеры и сложность, новые вопросы при повторном проходе, раздельное сохранение тем, миграция старого прогресса и введённых ответов, выбор, несколько пропусков, лишние блоки, история, словарь и импорт. Каждый из 2 343 вопросов проверяется, завершается и восстанавливается в тестовой среде.

Визуальный вид в браузере и мобильном Telegram не проверен: браузеры в среде проверки недоступны. Исправления импорта и сведения о выпуске практики β описаны в [заметках к выпуску](RELEASE-2026-10-04.md).

## Исправления 5 октября 2026

- После проверки ответ фиксируется, «Далее» доступно и при ошибке. Ошибка остаётся в истории и очереди повторений; повторный выбор и проверки заблокированы.
- Результат показывает краткий статус; пояснение доступно в раскрываемом «Разборе», без повторного блока подсказки и комментариев каждого варианта.
- Выбранные блоки сборки и пропусков исчезают из банка. Нажатие на блок в собранной фразе или заполненный пропуск возвращает вариант в банк. Выбор одного ответа можно отменить повторным нажатием до проверки.
- В заданиях выбора японского слова убраны русские варианты и фрагменты предложений. Варианты, отличающиеся только пунктуацией, объединены; ID старых вариантов мигрируют при загрузке сохранения.
- Формы глаголов перенесены с главной в меню «Практика»; настройки и сама тренировка остаются в этой вкладке.

Аудио пока не подключено. Для аудирования потребуются аудиофайл или ссылка, привязка к уроку, вопросы и правильные ответы, а для режима показа текста — расшифровка. Нынешние тексты оригинальные: готовые записи Genki требуют соответствующих заданий, а не простой подстановки записи под существующий текст. Плеер можно сделать стандартным HTML audio, с текстом в раскрываемом блоке и без автозапуска. Для первого примера достаточно одного трека с номером урока/упражнения и расшифровкой.

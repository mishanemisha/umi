# umi AI — «Объясни почему»

Небольшой сервер на Cloudflare Workers. В режиме «Формы глаголов» он показывает объяснение формы и 3 задания на закрепление. Приложение на GitHub Pages остаётся статическим, а ключ OpenAI хранится только в секретах этого сервера.

## Как это устроено

```
umi (Telegram Mini App) ──POST /v1/explain {form, seen}──▶ Worker ──▶ D1 (кэш объяснений)
        заголовок X-Telegram-Init-Data (подпись Telegram)     │ нет нового варианта и лимиты позволяют
                                                              └──▶ OpenAI Responses API (ключ — секрет воркера)
```

- **Объяснение не персональное.** На каждую из 99 форм хранится до `AI_MAX_VARIANTS` (4) вариантов «объяснение + 3 задания». Ученик получает вариант, которого ещё не видел. Когда все 4 варианта созданы, дальше всё отдаётся из базы, и OpenAI больше не вызывается.
- **Ученик ничего не отправляет модели.** Приложение передаёт только id формы и номера уже просмотренных вариантов. Слова, прогресс и имя на сервер не уходят. Модель не получает данных пользователя и не хранит ответы (`store: false`).
- **Японские ответы в заданиях строит наш движок** (`src/verbs.js`, тот же, что в приложении, — его сверяет тест). Модель только пишет русский текст и выбирает кандидатов по id. Правильный ответ поэтому всегда верный. Если модель нарушит правила, ответ отклоняется, после одной повторной попытки слот освобождается.

## Безопасность

| Риск | Защита |
|---|---|
| Ключ OpenAI утечёт из приложения | Ключа в приложении нет. Он хранится только в `wrangler secret`, в браузер не попадает, в логи не пишется |
| Кто-то будет дёргать сервер в обход Telegram | Каждый запрос проверяется по подписи `initData` (HMAC с токеном бота) и сроку давности (сутки). Без подписи — ответ 401, OpenAI не вызывается |
| Чужой сайт вызовет API из браузера | CORS разрешён только для `https://mishanemisha.github.io` (дополнительная мера к подписи) |
| Большой счёт | Ограничения: 10 новых генераций на пользователя в сутки, 300 запросов, суточный потолок `AI_DAILY_BUDGET_USD`, максимум 4 варианта на форму. Двойное нажатие не запускает вторую генерацию |
| Сломанный или вредный текст модели | Строгая JSON-схема, проверка ответа, вырезание разметки. Приложение выводит только экранированный текст. Кнопка «Ошибка в объяснении?» записывает жалобу в `ai_reports` |

Дополнительно в кабинете OpenAI:
- Отдельный проект только для umi.
- Ключ с ограниченными правами (Restricted, только нужные API).
- Месячный лимит расходов и уведомления на почту.

**Токены не присылайте в чат.** Вы вводите их сами в терминале командой `wrangler secret put` — так они не попадут ни в переписку, ни в репозиторий.

## Запуск (один раз, ~15 минут)

```sh
cd server
npx wrangler login                          # вход в Cloudflare (бесплатный аккаунт)
npx wrangler d1 create umi-ai               # создать базу; database_id вставить в wrangler.toml
npm run db:init                             # создать таблицы из schema.sql
npx wrangler secret put OPENAI_API_KEY      # вставить ключ OpenAI (ввод скрыт)
npx wrangler secret put TELEGRAM_BOT_TOKEN  # токен бота, через которого открывается umi (для проверки подписи)
npm run deploy                              # выдаст адрес https://umi-ai.<аккаунт>.workers.dev
```

Затем в `js/ai.js` указать этот адрес в `AI_API`, поднять `?v=` в `index.html` и опубликовать приложение.

Проверка без сервера: откройте приложение с `#aidemo` — выпадашка покажет пример ответа.
Тесты сервера: `cd server && npm test`. В них проверены подпись Telegram, кэш, лимиты, бюджет, повтор при плохом ответе и совпадение движка с приложением.

## Стоимость

Цены OpenAI на 14.10.2026, за 1M токенов (вход / кэшированный вход / выход):
- `gpt-6.1-sol`: $2 / $0.10 / $10
- `gpt-6-luna`: $0.10 / $0.01 / $0.50

Одна генерация: примерно 2 000 токенов на входе и 1 200 на выходе, включая рассуждение.

| | gpt-6.1-sol | gpt-6-luna |
|---|---|---|
| Одна генерация | ≈ $0.016 | ≈ $0.0008 |
| Все 99 форм × 4 варианта (потолок, разово) | ≈ $6.5 | ≈ $0.35 |
| Каждый следующий показ (из базы) | $0 | $0 |

Хостинг: бесплатный план Workers (100 000 запросов в сутки) и D1 (5 млн чтений в сутки) покрывает это с запасом. Итог: разовые ≈ $6–7 на прогрев базы, дальше около $0 в месяц при любом числе учеников. Новые генерации нужны, только если поднять `AI_MAX_VARIANTS` или сменить промпт (`PROMPT_VERSION` в `src/explain.js`).

## Таблицы (schema.sql)

- `ai_content` — варианты объяснений по формам: тело, модель, токены, стоимость, показы, жалобы.
- `ai_usage` — счётчики пользователя за сутки.
- `ai_budget` — расход за сутки.
- `ai_reports` — жалобы.

Снять плохой вариант: `UPDATE ai_content SET status='hidden' WHERE form_id=… AND variant=…`.

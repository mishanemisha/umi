# Данные: кандзи (`data/kanji/`)

## Назначение

Приложение загружает данные лениво, по одному знаку:

- `data/kanji/<hex>.json` — код Unicode в нижнем регистре без `U+` (書 → `66f8.json`). Открывается карточкой кандзи на обороте канваса квиза и словарём.
- `data/kanji/index.json` — версия данных, число знаков и строка всех знаков.

## Схема

### `<hex>.json`

| Ключ | Тип | Смысл |
|---|---|---|
| `v` | число | версия схемы (сейчас `1`) |
| `k` | строка | знак |
| `strokes` | число | число черт по KANJIDIC2 |
| `grade` | число | класс: 1–6 школьные, 8 общеупотребительные |
| `jlpt` | число | 5…1 = N5…N1; ключа нет, если уровня нет |
| `freq` | число | ранг частотности KANJIDIC2 (1–2501) |
| `radical` | объект | `c` — символ ключа, `n` — номер ключа (1–214), `v` — позиционная форма ключа (если есть), `ru` — название ключа (`mt`) |
| `parts` | массив строк | компоненты по KRADFILE; заменители заменены обычными символами |
| `on` | массив строк | онъёми (катакана) |
| `kun` | массив строк | кунъёми в формате KANJIDIC: `か.く`, `-が.き`; точка — граница окуригана |
| `nanori` | массив строк | именные чтения |
| `ru` | массив строк | русские значения (всегда `mt`) |
| `ru_src` | строка | всегда `"mt"` |
| `mt` | число | `1` — значения машинные |
| `en` | массив строк | английские значения KANJIDIC2 |
| `svg` | массив строк | `d` каждой черты в порядке рисования, из KanjiVG (координаты 0–109) |
| `words` | массив | до 10 слов, отсортированы по частотности |
| `sents` | массив | до 5 предложений |

`words[]`:

| Ключ | Смысл |
|---|---|
| `w` | слово |
| `r` | чтение слова (кана) |
| `kr` | чтение именно этого знака в слове (отсутствует у 69 слов) |
| `m` | русский перевод **строкой** (в `data/dict` это массив) |
| `id` | `jm<seq>`, номер статьи JMdict |
| `mt` | `1` — перевод машинный; отсутствует, если взят из `words.js` |

`sents[]`:

| Ключ | Смысл |
|---|---|
| `jp` | японское предложение |
| `ru` | русский перевод (Tatoeba) |
| `src.ja` / `src.ru` | ID предложения в Tatoeba (ссылка `tatoeba.org/sentences/show/<id>`) |
| `src.by` | `[ник автора jp, ник автора ru]`; `null` — автор не указан |

Ключи `nums`, `var`, `sim`, `note` описаны в исследовании (§4.1), но в файлах их нет.

### `index.json`

| Ключ | Смысл |
|---|---|
| `version` | дата KANJIDIC2 + релиз KanjiVG + дата JMdict, например `2026-10-20+kvg20260714+jm2026-10-20` |
| `count` | число знаков (2 136) |
| `kanji` | строка всех знаков в порядке сортировки |

## Примеры: разбивка на слова и ревью (2026-10-21)

Примеры в `sents` (иероглифы) и `sentences.json` (словарь) собирает `tools/sentences/build_sentences.py` поверх готовых данных — после `build_kanji.py` / `build_dict.py`:

```sh
python3 -I tools/sentences/build_sentences.py pool SRC   # кандидаты на ревью → tools/sentences/pool.tsv (не в репозитории)
python3 -I tools/sentences/build_sentences.py apply SRC  # одобренные примеры → data/kanji, data/dict
```

- Кандидаты — пары ja–ru из Tatoeba не длиннее 30 знаков, для которых есть разбивка на слова (индексы Tatoeba, CC BY 2.0 FR): 11 649 предложений.
- Ревью: `tools/sentences/review.tsv` — вердикт по каждому кандидату (8 агентов Claude Haiku, 2026-10-21). Одобрено 10 442, отклонено 1 207: дубликаты, неточный перевод, неестественный японский, смерть, политика, преступления, насилие, религия, грубость. В данные попадают только `ok`.
- У предложения есть `t` — токены `[форма с фуриганой «{漢字|かんじ}», лемма, чтение леммы, русское значение]`, пустые хвостовые поля опущены. Фуригана — из JmdictFurigana; значения слов — из банка приложения, `data/dict` и таблицы служебных слов в скрипте (русские глоссы JMdict не используются). Значение есть у ~93 % токенов.
- `src` — `{ja, ru, by:[автор японской фразы, автор перевода]}`; приложение показывает авторов чипами под каждым примером.

## Пересборка

Исходники скачиваются вручную и в репозиторий не кладутся. Каталог `SRC` (раскладка по `tools/kanji/build_kanji.py`):

```
SRC/kanjidic2/kanjidic2.xml.gz
SRC/jmdict/JMdict.gz
SRC/kradfile/kradfile.gz
SRC/kanjivg/kanjivg-*-main.zip
SRC/furigana/JmdictFurigana.txt
SRC/tatoeba/jpn-rus_links.tsv.bz2
SRC/tatoeba-detailed/jpn_sentences_detailed.tsv.bz2
SRC/tatoeba-detailed/rus_sentences_detailed.tsv.bz2
SRC/jlpt/kanji.json
```

```sh
python3 -I tools/dict/build_dict.py SRC_DICT          # сначала словарь (см. data/dict/README.md)
python3 -I tools/kanji/build_kanji.py SRC             # пишет data/kanji/ (удаляет старые *.json)
python3 -I tools/kanji/build_kanji.py SRC --todo DIR  # то же + списки непереведённого в DIR
```

Скрипт `build_kanji.py` читает `data/dict/words.json` (если он есть) для русских значений слов. Поэтому словарь собирают раньше. Раскладка `SRC` у двух скриптов разная (см. их docstring), поэтому для каждого удобнее отдельный каталог.

## Известные пробелы

- **Русский текст машинный.** Все значения знаков и 5 650 из 6 591 слова помечены `mt`. Собственного текста из `words.js` — 941 слово.
- **Атрибуция неполная.** В 619 из 6305 предложений автор не указан (`src.by` содержит `null`); приложение показывает номер фразы со ссылкой на Tatoeba. CC BY 2.0 FR требует указать автора, поэтому такие предложения нужно либо проверить, либо убрать.
- **Черты: 9 знаков, где число черт KANJIDIC2 расходится с KanjiVG** (`strokes` / число путей в `svg`): 僅 12/13, 葛 11/12, 賭 15/16, 遜 13/14, 謎 16/17, 遡 13/14, 牙 5/4, 餌 14/15, 餅 14/15. В `svg` при этом лежат все пути KanjiVG; номера черт и сетка кадров не реализованы (нет `nums`).
- **Метка `mt` шире, чем нужно.** Слова, для которых значение взято из `data/dict` (в том числе собственный текст банка), здесь помечены `mt: 1`.
- **Нет JLPT у 172 знаков**, нет `freq` у 99 знаков, нет `on` у 6 знаков.
- **Нет `var`, `sim`, `note`.** Секция «Ещё» карточки кандзи пока не может опираться на них.

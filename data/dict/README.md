# Данные: встроенный словарь (`data/dict/`)

## Назначение

Основа будущего встроенного словаря umi. Приложение пока не загружает эти файлы; сейчас они нужны для пересборки `data/kanji` (русские значения слов) и для словаря, который появится позже.

- `words.json` — 6 005 слов с русскими значениями, частью речи, фуриганой, уровнем JLPT и ссылками на примеры.
- `sentences.json` — 9 020 примеров ja–ru из Tatoeba. Слова ссылаются на них по индексу.

## Выкатка: 30 % слов (2026-10-21)

Сейчас в репозитории — пробная выкатка: `--size 1800`. Это 1 927 слов (882 из банка `words.js` + самые частотные), из них 1 040 переведены машинно (`mt: 1`), 1 500 с примерами; 3 767 предложений, у 146 автор не указан. Цифры ниже описывают полную сборку (`--size 6000`); чтобы вернуть её, пересоберите с этим параметром, затем пересоберите `data/kanji`.

## Схема

### `words.json` (массив объектов)

| Ключ | Смысл |
|---|---|
| `id` | `jm<seq>` — номер статьи JMdict; для 5 слов банка, которых нет в JMdict, `umi:<слово>` (二年, 千人, 百人, 男女差, 社報) |
| `w` | написание |
| `r` | чтение (кана) |
| `m` | массив русских значений (не менее одного) |
| `pos` | массив кодов части речи (см. таблицу ниже) |
| `jlpt` | уровень 5…1 = N5…N1; ключа нет, если уровня нет |
| `k` | фуриганная разбивка: массив `{c, r}` — знак и его чтение; есть у 5 117 слов |
| `f` | порядковый номер 1…6 005 по убыванию частотности |
| `s` | индексы записей `sentences.json` (до 3) |
| `mt` | `1` — значения из `ru_overrides.tsv` (машинный перевод); ключа нет, если значения из `words.js` |

### `sentences.json` (массив объектов)

| Ключ | Смысл |
|---|---|
| `jp` | японское предложение |
| `ru` | русский перевод |
| `src.ja` | ID японского предложения в Tatoeba |
| `src.ru` | ID русского перевода в Tatoeba |
| `src.by` | `[ник автора jp, ник автора ru]`; `null` — автор не указан |

## Пересборка

Исходники скачиваются вручную и в репозиторий не кладутся. Каталог `SRC` (раскладка по `tools/dict/build_dict.py`):

```
SRC/jmdict/JMdict.gz
SRC/furigana/JmdictFurigana.txt
SRC/jlpt/n1.csv … SRC/jlpt/n5.csv
SRC/tatoeba_jpn_detailed/jpn_sentences_detailed.tsv
SRC/tatoeba_rus_detailed/rus_sentences_detailed.tsv
SRC/tatoeba_links/jpn-rus_links.tsv
SRC/tatoeba_indices/jpn_indices.csv
```

```sh
python3 -I tools/dict/build_dict.py SRC [--out data/dict] [--todo todo.tsv] [--size 6000]
```

- `--size` — число записей JMdict, отбираемых по рангу (по умолчанию 6000). Сверх него попадают принудительно включённые слова банка и JLPT.
- `--todo` — записи без русского значения (с английскими глоссами) для `ru_overrides.tsv`.
- `--audit` — все отобранные записи с русскими значениями для проверки.

Пересборка перезаписывает `words.json` и `sentences.json`. После неё запускают `tools/kanji/build_kanji.py`.

Русские значения выбираются в таком порядке: `words.js` → `tools/dict/ru_overrides.tsv` (помечается `mt`). Записи без значения отбрасываются.

## Известные пробелы

- **Авторы примеров не указаны у 1 225 предложений из 9 020 (13,6 %)**: `src.by[0]` равен `null`. CC BY 2.0 FR требует указать автора. Такие примеры либо проверить, либо не показывать.
- **Машинный перевод.** 85 % значений помечены `mt`. В данных не отмечено, какая часть проверена вручную.
- **Отбор смыслов в загрузчике JMdict.** `build_dict.py` берёт смысл только тогда, когда все его глоссы английские. Смысл с русским глоссом в нём пропускается целиком, включая английский. Русский текст из JMdict при этом не читается, но часть английского материала теряется.
- **Файла `data/dict/LICENSE` нет.** В исследовании (§4.2) предусмотрен файл с CC BY-SA 4.0 и перечнем источников; его ещё нужно написать.
- **Записей 6 005, а не ровно 6 000:** см. `--size` выше.
- **Слова банка без записи в JMdict** (5 штук) получают `id` вида `umi:<слово>`; у них нет `jlpt` и `f` вычисляется так же, как у остальных.
